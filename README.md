# CP Maintenance — pagine pubbliche e aggiornamenti

Repository **pubblico** di CP Maintenance (programma interno di CP Multiservice S.r.l.s.). Contiene solo:
- la pagina del programma (`index.html`) e l'informativa sulla privacy (`privacy.html`), pubblicate con GitHub Pages;
- i pacchetti firmati degli aggiornamenti automatici: installatori nelle release, `aggiornamenti/latest.json` (ultima versione) e `aggiornamenti/precedente.json` (versione precedente).

Non contiene codice sorgente né dati.
